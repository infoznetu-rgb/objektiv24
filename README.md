# Objektív24

Nová statická verzia webu Objektív24 pripravená na GitHub Pages.

## Stav

- responzívna titulná stránka
- vyhľadávanie a filtrovanie tém
- časovo neaktuálne články oddelené do archívu
- aktualizovaná stránka „Ako pracujeme“
- dátová vrstva `data/articles.json` pripravená na neskoršiu automatizáciu

## Náhľad

Po zlúčení vetvy `site-v1` do `main` je možné web publikovať cez GitHub Pages.

## Plán automatizácie

Ďalší krok môže pravidelne načítavať vybrané RSS/API zdroje, ukladať nové podklady ako návrhy a publikovanie ponechať na manuálne potvrdenie.
